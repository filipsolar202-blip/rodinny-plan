# Označování vydání

Uživatel požaduje viditelné číslo každé nové zveřejněné verze.

- Před každou další aktualizací na GitHub Pages zvyšte verzi v `package.json` a `src/version.js` současně.
- Pro drobné úpravy zvyšte poslední číslo, pro větší funkční rozšíření prostřední číslo.
- Číslo zobrazujte úplně dole v postranním panelu pod „Fair Life · Filip Solár“.
- Před zveřejněním spusťte sestavení; kontroluje shodu obou čísel. Po nasazení ověřte viditelné číslo na živém webu.
